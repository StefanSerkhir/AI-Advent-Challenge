# Перенос Compose → Web: функциональный паритет

Список составлен по исходным `DesktopApp.kt`, `MarkdownBlocks.kt`, обработчикам
Compose, контроллеру, сценариям и тестам до реализации web-слоя.

| Возможность исходного UI | Реализация web |
| --- | --- |
| DeepSeek / OpenAI, текущий набор моделей, отдельный выбор модели для каждого провайдера | Каталог `/api/state`, панель подключения, `WorkbenchController.modelSelections` |
| Сохранение и замена ключа, пустое поле после успеха, признак настроенного ключа | `/api/key`, атомарный `LocalConfigStore`, клиент получает только `hasKey` |
| Сравнение двух ответов; с ограничениями; без ограничений | Прежний `PromptRunner`, отдельные карточки и таблица метрик |
| 4 способа рассуждения и демо с эталоном | Прежний `ReasoningRunner`, все 4 решения, созданный промпт и оценка |
| Температуры 0 / 0.7 / 1.2 и демо | Прежний `TemperatureRunner`, фактически использованная модель, оценка |
| GPT-5.6 Luna / Terra / Sol, слепой оценщик Sol | Прежний `ModelComparisonRunner`, A/B/C, частичные ошибки, время, стоимость и токены каждого вызова |
| При включении сравнения моделей — OpenAI, лимит минимум 1000; затем ручной лимит разрешён | Правило перенесено из обработчика Compose в общий контроллер; API блокирует смену подключения внутри режима |
| Лимиты токенов, слов, пунктов, включение/редактирование stop sequence | Настройки на сервере, положительные целые числа, проверка stop sequence; параметры вызова не изменены |
| История по умолчанию включена, отдельные ветки, счётчики ходов | `PromptRunner`, постоянный `.llm-history.json`, оба счётчика; режимы экспериментов не используют историю |
| Очистка истории отдельно от экрана | `DELETE /api/history` и `DELETE /api/results` |
| Предыдущие запросы и все варианты результатов | Список экспериментов в серверном состоянии; восстановление после перезагрузки |
| Символы Unicode, слова, completion tokens, finish_reason | Расчёт на Kotlin по прежней методике, таблицы с прокруткой |
| Время, input / completion / reasoning / total tokens, стоимость и сумма | Прежние тарифы и расчёт `ModelComparisonTarget`, без изменения методики |
| Прогресс, streaming-текст, текущий этап, отмена, блокировки и уведомления | REST-команды, SSE-снимки StateFlow, явный номер операции; накопленный текст и готовые этапы сохраняются также при ошибке/отмене |
| Ctrl+Enter и Cmd+Enter | Обработчик поля запроса с защитой от IME и повторной отправки |
| Markdown, таблицы, код, формулы | react-markdown + GFM + KaTeX; raw HTML выключен, LaTeX `\[ \]`, `\( \)` поддерживается вне кода |
| Загрузка/сохранение `.env`, legacy `llm_api_key`, неизвестная модель из конфигурации | Прежние `AppBootstrap` и `LocalConfigStore`; формат сохранён |
| Температурный fallback Luna → gpt-4.1-mini; независимые запросы; reasoning_effort=medium | Существующий слой `llm/` без изменения модели/параметров |

## Дополнительные проверки переноса

- `WorkbenchApiTest`: настройки/ключи/валидация/сохранение, запуск без ожидания LLM,
  SSE при присоединении, отключение SSE без отмены, отмена и новый запрос,
  идемпотентный повтор, запрет изменений во время работы, устаревшие версии,
  конкурентный запуск и обновление настроек, шесть режимов, демо, раздельная
  очистка, частичные успехи и отсутствие ключей в ответах.
- Playwright: шесть режимов через UI, два демо, оба сочетания клавиш, сохранение
  ключа и очистка поля, счётчики истории, reload во время запроса, две вкладки,
  offline/reconnect, потерянный HTTP-ответ и повтор той же команды, отмена и новый
  запрос, сетевая ошибка LLM, частичная ошибка модели, длинный Markdown, код,
  формулы, запрет HTML/JS, desktop и узкое окно 430 px.
- Тестовый сервер находится в `src/test`: детерминированные ответы, временные
  `.env` и `.llm-history.json`, без доступа к ключам пользователя и без обращений
  к провайдерам.
