# LLM CLI

Kotlin-приложение, которое дважды отправляет один базовый запрос в LLM и
выводит ответы в консоль для сравнения. Для HTTP-запросов используется Ktor.

- первый вызов не задаёт ограничений ответа;
- второй добавляет формат из трёх пунктов, лимит в 60 слов, API-лимит в
  300 токенов и условие завершения `<END_OF_RESPONSE>`.

Для лимита токенов приложение автоматически использует параметр
`max_tokens` в DeepSeek и `max_completion_tokens` в OpenAI. DeepSeek также
получает `<END_OF_RESPONSE>` как API-параметр `stop`; выбранная OpenAI-модель
его не поддерживает, поэтому для неё действует явная инструкция в запросе.

Поддерживаемые провайдеры:

- `Deepseek` — модель `deepseek-v4-flash`, используется по умолчанию;
- `OpenAI` — модель `gpt-5.6-luna`; также поддерживается значение `ChatGPT`.

## Требования

- JDK 21;
- доступ в интернет;
- API-ключ выбранного провайдера;
- доступный баланс на аккаунте провайдера.

API-ключ можно создать в панели
[DeepSeek](https://platform.deepseek.com/api_keys) или
[OpenAI](https://platform.openai.com/api-keys).

## Настройка через `.env`

Создайте локальный файл конфигурации из примера:

```bash
cp .env.example .env
```

Для DeepSeek:

```dotenv
llm_api_key=ВАШ_DEEPSEEK_API_KEY
llm_kind=Deepseek
```

Для OpenAI:

```dotenv
llm_api_key=ВАШ_OPENAI_API_KEY
llm_kind=OpenAI
```

Файл `.env` добавлен в `.gitignore` и не должен попадать в репозиторий.
Ключи DeepSeek и OpenAI не взаимозаменяемы.

## Запуск

Для удобного запуска используется launcher `llm`. Он передаёт приложению все
аргументы после своего имени, поэтому `--args` и кавычки вокруг запроса не нужны:

```bash
./llm Объясни почему небо голубое
```

В zsh символы `?`, `*` и `[]` используются для поиска файлов ещё до запуска
приложения. Чтобы передать их без кавычек и экранирования, добавьте `noglob`:

```bash
noglob ./llm Почему небо голубое?
```

Если запрос не передан, используется тестовый текст
`Объясни, как искусственный интеллект меняет образование.`:

```bash
./llm
```

Провайдера и ключ можно указать прямо при запуске:

```bash
./llm --llm_kind=OpenAI --llm_api_key=ВАШ_КЛЮЧ Объясни корутины Kotlin
```

Стандартный запуск через Gradle также остаётся доступен:

```bash
./gradlew run --args='Почему небо голубое?'
```

Поддерживаются обе формы записи параметров:

```text
--llm_kind=OpenAI
--llm_kind OpenAI
```

## Входные параметры

| Параметр | Обязательный | Значение по умолчанию | Описание |
| --- | --- | --- | --- |
| `--llm_api_key` | Да, если ключ не задан в окружении или `.env` | Нет | API-ключ выбранного провайдера |
| `--llm_kind` | Нет | `Deepseek` | Провайдер: `Deepseek`, `OpenAI` или псевдоним `ChatGPT` |
| Позиционный текст | Нет | `Объясни, как искусственный интеллект меняет образование.` | Базовый запрос, дважды отправляемый модели |

## Переменные окружения

Вместо `.env` можно использовать переменные окружения:

```bash
export llm_api_key=ВАШ_КЛЮЧ
export llm_kind=OpenAI
./llm Привет!
```

Настройки применяются в следующем порядке приоритета:

1. CLI-параметры `--llm_api_key` и `--llm_kind`;
2. переменные окружения `llm_api_key` и `llm_kind`;
3. значения из файла `.env`;
4. `Deepseek` как провайдер по умолчанию.

## Проверка проекта

Сборка:

```bash
./gradlew build
```

Тесты:

```bash
./gradlew test
```

## Структура

- `Main.kt` — точка входа;
- `llm` — launcher для запуска без `--args`;
- `cli/` — разбор параметров запуска;
- `config/` — загрузка переменных окружения и `.env`;
- `network/` — создание Ktor-клиента;
- `llm/` — общий интерфейс, фабрика и реализации провайдеров.
